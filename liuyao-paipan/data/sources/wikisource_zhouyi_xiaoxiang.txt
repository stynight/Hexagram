X 七日得，以中道也。
X 三年克之，憊也。
X 終日戒，有所疑也。
X 東鄰殺牛，不如西鄰之時也；實受其福，吉大來也。
X 濡其首厲，何可久也。
#未濟
X 濡其尾，亦不知極也。
X 九二貞吉，中以行正也。
X 未濟征凶，位不當也。
X 貞吉悔亡，志行也。
X 君子之光，其暉吉也。
X 飲酒濡首，亦不知節也。
