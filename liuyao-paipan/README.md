# 六爻納甲排盤

單一 HTML 檔，所有程式碼與《周易》原文都在 `liuyao.html` 裡，下載後用瀏覽器打開就能用，不需要網路，也不載入網路字型。

## 頁面

- 起卦：三種方式。
  - 數字：第一數除以 8 取上卦、第二數除以 8 取下卦（餘 0 取坤），三數之和除以 6 取動爻（餘 0 取上爻），先天數乾1 兌2 離3 震4 巽5 坎6 艮7 坤8；算式逐步顯示，大數字也照算。
  - 六爻：由上到下點選六個爻，每爻四種：少陽、少陰、老陽（動）、老陰（動）。
  - 時間：梅花易數年月日時起卦。年取農曆年地支數（子1 … 亥12），月、日用農曆（閏月按本月數），時取時支數；(年＋月＋日)÷8 上卦，(年＋月＋日＋時)÷8 下卦，總數÷6 動爻。
  - 日期時間預設現在，可改；時區預設本機，也可指定；「子時換日」勾選時 23:00 起算次日，不勾時 23:00–24:00 為夜子時（日柱用當天、時干用次日）。右側即時顯示四柱、月建日辰、旬空、農曆與前後節氣。
- 排盤：本卦、變卦（宮、世代、六沖六合、遊魂歸魂）；每爻的六神、伏神、六親、納甲干支與五行、世應、動爻記號與變爻，下方標出月破、日沖、暗動、日破、臨月建、臨日、月合、合起、合絆、旬空、生旺墓絕，以及動爻的回頭生剋、化進化退、化空化破、化墓化絕、回頭沖合。點一爻可聚焦它的關係；點一條關係會在表上標出相關的爻。可存成卦例、複製文字盤。
- 關係清單：見下節。
- 原文：本卦卦辭與大象、動爻爻辭與小象、變卦卦辭與大象、變卦中與動爻同位之爻的爻辭與小象；乾坤六爻全動另列用九、用六。可切換同時列出本卦六爻全文。
- 卦例：存檔、改名、刪除（頁內確認）、打開、匯出 JSON、匯入 JSON。發布成 Artifact 並登入時存在帳戶裡，換裝置也看得到；單獨打開 HTML 時存在瀏覽器。
- 設定：十二種配色加跟隨系統（與八字排盤同一套）、原文避字開關、關係清單分數開關、「最要緊」條數滑桿。

## 關係清單

先論合沖、再論生剋，每條都列，弱的也不藏。最上面「最要緊」是力量最強的幾條（預設 5 條，可調 3–8），下面依序是合沖、生剋、旬空三段，各自依力量排序；每條只出現一次。

力量 0–100 ＝ 施力者 × 關係類型 × 施力爻的旺衰。施力者由強到弱：日辰、月建，變爻對本位動爻，動爻，暗動爻，靜爻。旺衰以月令為主（臨月建、旺、相、月合為旺相；休、囚、死、月破為休囚），日辰生扶、回頭生、化進加分，日剋、合絆、回頭剋、化退、化空、化破、化墓、化絕減分。同分時合沖排在生剋前。

收錄的關係：

- 月建、日辰對每一爻、每個變爻、每個伏神：沖（月破、暗動、日破、沖散、沖空則實）、合（月合、合起、合絆）、臨、扶、生、剋、洩、耗，以及爻在日辰的長生、帝旺、墓、絕。
- 變爻對本位動爻：回頭生、回頭剋、回頭沖、回頭合（化扶）、化進、化退、化比和、化洩、化耗、化長生、化旺、化墓、化絕、化空、化破、化伏吟。
- 動爻、暗動爻對他爻與伏神：沖、合、生、剋、扶、同支。兩爻都在動時，沖合只列一次。
- 靜爻旺相對靜爻休囚的生剋，靜爻之間的沖合（力量最弱）。
- 飛伏：飛來生伏、飛來剋伏、伏去生飛、伏剋飛神、飛伏比和、飛伏沖合，以及能否出伏（提拔：月建日辰動爻生扶伏神；推開：飛神旬空、月破、被沖剋）。
- 世應關係；卦級的六沖、六合、六沖化六合等；卦反吟、三爻回頭沖、伏吟；三合局（成局、虛一待用、未成）。

## 採用的規則

- 納甲、八宮世應、六親：《增刪卜易》渾天甲子章、八宮圖、世應章、六親歌章。六親以本卦卦宮五行為我，變爻六親也以本卦卦宮論。
- 六神：甲乙青龍、丙丁朱雀、戊勾陳、己螣蛇、庚辛白虎、壬癸玄武，由初爻起。
- 伏神：本卦缺的六親，取本宮首卦（八純卦）同一六親之爻，伏於本卦同位之下。
- 旺相休囚：以月令定（四時旺相章）；臨月建、同五行為旺，月生為相；未月之火、丑月之水另註有餘氣。
- 暗動、日破：靜爻旺相逢日沖為暗動，休囚逢日沖為日破；旬空逢日沖為沖空則實（暗動章、日辰章）。
- 動爻逢日沖：旺相不散，休囚恐散（動散章）。動而逢合為合絆，靜而逢合為合起（六合章）。
- 變爻只生剋沖合本位之動爻，不生剋他爻；日月可生剋動爻、靜爻、變爻、飛爻、伏爻（動變生克沖合章）。
- 靜爻旺相可生剋休囚之爻（動靜生克章）。
- 生旺墓絕只取這四個，土隨水：長生申、旺子、墓辰、絕巳（生旺墓絕章）；土爻旺相化巳，論生不論絕。
- 進神：亥化子、寅化卯、巳化午、申化酉、丑化辰、辰化未、未化戌、戌化丑；退神反之（進神退神章）。
- 三合成局：三爻皆動；兩爻動一爻靜；同一卦內初三爻或四六爻動，變出之爻補足。暗動作動論。兩爻動缺一者為虛一待用（六合章）。
- 旬空：動不為空、沖空則實、旺而逢空出旬可用、空又逢破、月令剋之為真空（旬空章）。
- 飛伏生剋：伏剋飛神為出暴、飛來剋伏反傷身、伏去生飛名洩氣、飛來生伏得長生、飛伏比和為有助（《卜筮正宗》飛伏生剋吉凶歌）；伏無提拔終徒爾、飛不推開亦枉然、空下伏神易於引拔（《黃金策》）。
- 卦反吟：內外卦乾巽、坎離、艮坤、震兌互變；三爻皆回頭沖另列（反伏章）；伏吟：乾震互變，地支不變。

## 曆算

- 節氣用 VSOP87 截斷級數求太陽視黃經、ΔT 用 Espenak–Meeus；農曆用 Meeus 真朔與中氣置閏。`src/calendar.js` 的第 2–5 節沿用同倉庫 `bazi-paipan/src/engine.js`，唯一改動是民國元年至十七年（1912–1928）的朔日改用北京地方平時判日，使 1914、1916、1920 三個朔在午夜前後的月份與官方曆書一致。
- 年柱以立春、月柱以節的絕對時刻比對；日柱、時柱用輸入時區的鐘面時間，時柱用五鼠遁。
- `node tests/calendar-check.js 1901 2099` 與 lunar-javascript 逐日、逐節氣對照：4776 個節氣最大差 36 秒；72684 天日柱全同；77460 個時刻（每日正午與每個節前後三分鐘）年柱、月柱全同；農曆只有 2057 年九月朔一個月不同，本工具與壽星天文曆（sxtwl）同為 9 月 28 日初一。
- 可用年份 1901–2099。

## 原文

三個來源逐字比對：ctext 系的卦爻辭與大象（npm 套件 opencode-tianji 內附資料）、維基文庫《周易》各卦頁、朱熹《周易本義》（四庫本）；三者分歧時以《周易正義》裁定。小象以維基文庫為底本，依《周易本義》校正。共 48 處修正，逐條列在 `data/zhouyi_patches.json`，來源文字放在 `data/sources/`。

原文裡有兩處正好是使用者避用的那個字（晉卦辭「晝日三□」、蒙卦九二小象「剛柔□也」）。資料中以〓佔位，畫面預設顯示□並加註，設定裡可切換顯示原字；原始碼與組好的 HTML 都不含那個字，`build.js` 會檢查。

## 驗收用例（全部通過）

1. 題目給定：數字 4、6、2，2026-10-17 10:00（丙午年 戊戌月 甲子日 己巳時）→ 雷水解上六動。世在二爻戊辰土妻財、應在五爻庚申金官鬼；上六庚戌土動化己巳火（回頭生、化絕，土爻旺相論生不論絕）；變卦火水未濟；父母庚子水伏在初爻戊寅木下（伏去生飛、伏神臨日）；旬空戌亥；世爻月破；三、四爻午火日破；六神青龍起初爻；關係第一條為世爻月破。
2. 時間起卦：2026-02-27 08:00（農曆正月十一辰時，丙午 庚寅 壬申 甲辰）→ 年午7＋1＋11＝19 得離，＋辰5＝24 得坤，24÷6 上爻動：火地晉（乾宮遊魂，世四應初）化雷地豫（六合）。上九己巳火官鬼化庚戌土父母：化洩、化墓、化空；日辰申合二爻巳火為合起、合上九為合絆；子孫甲子水伏初爻乙未土下（飛來剋伏、日生、長生於日；提拔與推開皆有）；應生世。
3. 手動六爻：2026-03-11 12:00（丙午 辛卯 甲申 庚午，旬空午未），水雷屯六四、九五、上六動 → 火雷噬嗑。四爻申化酉：化進神、化帝旺、化破；五爻戌化未：化退神、化空；上爻子化巳：化耗、化絕；世爻寅木旺相逢日沖為暗動；申子辰兩動一靜成水局，寅午戌缺午為虛一待用；外卦坎化離為卦反吟；妻財戊午火伏三爻庚辰土下且旬空；世剋應。

## 開發

原始碼在 `src/`，`node build.js` 組成 `dist/liuyao.html`（獨立檔，同時複製到資料夾根目錄）與 `dist/artifact.html`（給 Artifact 發布）。

- `node tests/acceptance.js`：三個驗收用例與規則表檢查（加參數 `liuyao.html` 則測組好的檔）。
- `node tests/calendar-check.js [起年] [迄年]`：曆算互核，需要先 `npm install`（devDependencies 有 lunar-javascript）。
- `node tests/ui.js [截圖資料夾]`：用 Playwright 在桌面 1366 與手機 390 寬度走一遍所有控制項，檢查橫向溢出、元素超框與主控台錯誤。
- `data/build_text.py`：從 `data/sources/` 重新組出 `data/zhouyi.json` 與校勘清單。
