# 八字排盤合盤

單一 HTML 檔，所有程式碼都在 `bazi.html` 裡，用瀏覽器打開就能用，完全不需要網路（字型用裝置內建的宋體、明體，不下載網路字型）。

## 頁面

- 排盤：姓名、男女、公曆／農曆／四柱三種輸入，出生地（經緯度與時區），夏令時、真太陽時、早晚子時，排盤後可自動存入案例；下方「即時起局」卡片點一下就排現在這一刻。四柱輸入不必在六十甲子裡捲動：先點一柱，再點天干、地支，陽干只列陽支、陰干只列陰支；月干、時干照五虎遁、五鼠遁從年干、日干帶出，只要點地支，點完地支會跳到下一柱。也可以在文字框打字或貼上（例如「丙午 庚寅 壬辰 甲辰」，不加空白也行，夾著「乾造」、日期之類的字會略過，超過四柱只取前四柱；陰陽不合或不足四柱時會提示）。
- 案例：存檔、改名、刪除（頁內確認）、再打開。發布成 Artifact 並登入時存在帳戶裡，換裝置也看得到；單獨打開 HTML 時存在瀏覽器。列表上方與電腦版導覽列下方會顯示存放狀態（見「帳戶同步」）。
- 基本排盤：四柱的主星、天干、地支、藏干、副星、星運、自坐、空亡、納音、神煞，天干留意、地支留意，節氣交界盤提示與基本信息。
- 專業細盤：左邊流時、流日、流月、流年、大運（未起運時為小運）加原局四柱；右邊起運、交運、日柱旬空、歲數、司令，以及大運、流年、流月、流日、流時五條可橫滑的干支條。打開時預設選中今天，今天所在的格子頂端有主題色小菱形（主色偏紅的胭脂、暖橙等改用金色，與紅色的「沖」標記分得開）；點流月才出現流日，點流日才出現流時。胎命身可開關。
- 複製：抬頭的「複製」可挑三種格式，都不含姓名：四柱（「丙午 戊戌 乙丑 乙酉」）、乾坤造加四柱、完整資料（再加公曆與時區、真太陽時、農曆與時辰、起運、各步大運）。複製成功後視窗關上並提示；瀏覽器不讓網頁寫入剪貼簿時，會把那段文字選好，按 Ctrl+C（手機長按）即可。在命盤表裡拖選也會按柱複製，範圍取起點與終點兩格圍出的長方形：只圍到日期、主星、天干、地支這幾列時得到一行四柱；圍到其他列時每列一行、格子用 Tab 隔開（可貼進試算表），天干地支合成「干支」一列，五行小字不帶出來；還沒選的流日、流時欄與設定裡隱藏的列略過；只選一格裡的字時照瀏覽器原本的方式複製。
- 合盤：兩邊各自從案例選或新增，開始合盤後兩張細盤並排（手機上下），兩邊的流年月日時同步；下方有互看十神、五行互補與兩人之間的關係清單。另有「干支條也對照對方原局」開關（見「合盤對照對方」）。
- 設定・顯示項目：命盤表的每一列（主星、沖合、藏干、副星、星運、自坐、空亡、納音、神煞）、五條干支條、格子裡的沖合標記，以及各段資料與說明都能勾選隱藏；細盤表的動態欄可選「全部五欄／大運與流年／只留流年／只看原局」，手機上太擠時只留一兩欄，其餘看干支條（關係清單照樣計算全部層級）。表格很窄時，未選欄位的提示改用三個字（「先選日」「先選月」），沖合列的標記會在格子裡折行，不壓到隔壁格；納音字稍微縮小、左右留空，不再連成一串。手機版（寬度 900 以下）與電腦版分開記，另有「精簡模式」與「全部顯示」；手機的精簡模式另外把動態欄減到大運與流年。有項目被隱藏時，頁底會出現提示，點一下回到設定。
- 設定・神煞查法：流派有分歧的九處可以切換，另有每個神煞的查法說明（見「神煞」）。
- 設定・主題：十二種預設配色（月白、素白、青瓷、霧藍、冰晶、暖橙、胭脂、宣紙金，以及墨夜、夜金、深青、紫夜四種深色），另有「跟隨系統」與自訂色盤。自訂只要挑底色、卡片、文字、主色、抬頭帶、抬頭文字六個顏色，其餘線條與淺底自動混出；深淺依卡片顏色判斷，五行字色跟著換成適合的版本。主色如果跟卡片顏色太像（例如都設成白色），畫面會自動往文字色加深，直到對卡片的對比達到 3，選中的格子、按鈕與今天的小菱形才看得見；色盤裡記的仍是原本選的顏色，內建主題都在 3 以上不受影響。設定記在瀏覽器。

## 整柱標記

干支條每一格底部、細盤表的「沖合」列，都拿該柱與原局四柱比對：紅點「沖」是天剋地沖（天干相剋或相沖，且地支相沖），綠點「合」是天合地合（天干五合，且地支六合），金點「伏」是伏吟（干支完全相同）；後面的字是原局哪一柱，牽到日柱的點較大。原局欄則比對其餘三柱。今天的標記是格子頂端的小菱形，用主題色；主色偏紅（色相在紅色附近）時改用金色，與這些標記的顏色、形狀、位置都不同。

## 合盤對照對方

合盤頁的「干支條也對照對方原局」打開後，A 的大運、流年、流月、流日、流時（以及細盤表的各欄）除了對照 A 自己的原局，也對照 B 的原局，B 那邊亦同。對方原局的標記用空心點，前面加對方代號（例如「B沖日」）。同一格同時天剋地沖到兩人時，格子右上角有紅色折角；同時天合地合到兩人時是綠色折角。開關打開時，下方另列「流年同時牽動兩人」：今年前十年到後二十年裡，同一流年對兩人原局都是天剋地沖（或都是天合地合）的年份，點一下兩邊細盤一起跳到那一年；這段期間沒有時，會再說明是否整個六十甲子都不會發生。開關記在瀏覽器。

## 關係清單

每條關係都列出並標來源，分「底色」與「此刻」兩欄。分數＝類型分 × 位置係數 × 力量係數，所有係數都有滑桿、頁面上寫著預設值，調整後即時重排；每欄分數最高的幾條置頂高亮，低於折疊門檻的收在「展開較弱的 N 條」裡。合只標「合」並註明理論上化什麼，不判斷化不化。

天剋地沖、天合地合、伏吟（預設類型分 9、8、6，可調）成立時，同一對柱子之間的天干、地支關係（例如天干相沖、地支相沖，丑未、寅申的相刑，寅亥、巳申的相破，辰午酉亥的自刑）收在整柱那一條底下顯示，只計整柱這一次分；地支有旬空時，整柱這一條同樣折減。天干留意、地支留意兩行仍逐條列出，「整柱留意」另列。

## 速度

先量再改。`node tests/perf.js` 用 Playwright 把 CPU 降速四倍、手機 390 寬，每個情境量三次取中位數。冷開是瀏覽器裡還沒有存檔的第一次，熱開是同一個瀏覽器再開。

| 情境 | 首次繪製（改前 → 改後） | 冷開畫完 | 熱開畫完 |
|---|---|---|---|
| 排盤頁 | 208 → 168 ms | 160 → 117 ms | 130 → 77 ms |
| 上次在專業細盤 | 504 → 96 ms | 469 → 416 ms | 287 → 196 ms |
| 上次在案例（20 筆） | 524 → 100 ms | 453 → 430 ms | 416 → 99 ms |
| 上次在合盤 | 676 → 80 ms | 616 → 504 ms | 390 → 280 ms |

做法：

- 開頁先畫框架：導覽列與目前頁的佔位先出來，命盤在下一個畫面才算；排盤頁的表單在靜態 HTML 裡先藏著，不會先閃一下表單再換頁。
- 看到哪頁才算哪頁：表單近千個選項到第一次打開排盤頁才建；農曆月份到切換農曆輸入才算；上次的命盤到真正要畫時才算。
- 節氣算過就存起來：每年 24 個節氣時刻存在瀏覽器（約四百年封頂），下次打開就讀存檔；農曆置閏用的冬至也改讀同一份。存檔帶版本號，曆算公式改了會自動作廢。
- 干支條先一次量完所有條的位置，再一起設定捲動與捲軸，不再每條各觸發一次整頁排版（合盤有十條，這一項省最多）。
- 字型：已不載入任何網路字型，宋體用裝置內建的；實測把宋體全換成黑體，速度沒有差別，所以維持現狀。

## 帳戶同步

案例頁上方（電腦版另在導覽列下方）顯示存放狀態：「案例存在這個瀏覽器」（沒有帳戶，或單獨打開 HTML）、「正在讀取帳戶裡的案例…」、「已同步到你的帳戶・時間」、「儲存中…」、「帳戶同步中斷」。刪除案例時，除了刪掉帳戶裡那一筆，另寫一筆「已刪除」紀錄（含刪除時間）；別台裝置的瀏覽器若還留著舊快取，同步時會依紀錄一併移除，不會再把刪掉的案例傳回帳戶。判斷規則是：案例最後修改時間不晚於刪除時間，就當作已刪除；萬一還開著舊版頁面、把刪掉的案例又傳回帳戶，新版打開時會照紀錄把它清掉。刪除之後又按「存檔」重新存回，或在刪除之後才改過的那一份，算是新的，會保留（重新存檔時也會撤掉那筆已刪除紀錄）。正在看的盤如果標著「已存檔」，同步後卻發現已被刪掉，抬頭會改回「存檔」按鈕。只存在這個瀏覽器、帳戶裡沒有也沒被刪過的案例，同步時會補存進帳戶。

## 採用的算法與約定

- 編號：甲0…癸9，子0…亥11；五行木0火1土2金3水4。干的五行＝編號整除2；支的五行按 (支−2) mod 12 每三個一季、依次木火金水、每季第三個為土。十神＝(對方五行−日主五行) mod 5，陰陽同為偏、異為正；地支十神取本氣。
- 節氣：VSOP87 截斷級數求太陽視黃經，ΔT 用 Espenak–Meeus 多項式（沿用舊版引擎，已對照國立天文台與參考截圖，誤差在一分鐘內）。年柱以立春、月柱以節的絕對時刻比對；日柱以 1949-10-01 為甲子日；時柱用五鼠遁。
- 子時：預設 23:00 換日；勾選「早晚子時」時 23:00–24:00 日柱不換、時干用次日。
- 真太陽時：(經度 − 時區中央經線) × 4 分鐘，再加均時差。年、月柱仍以絕對時刻比對節氣，日、時柱用真太陽時的鐘面。
- 起運：出生到下一個（順排）或上一個（逆排）節的時間，三天折一年、一天折四個月、一個時辰折十天（一年按 360 天、一月按 30 天）。交運日期是出生時刻依序加上這些年月日時。
- 歲數：大運起始歲數與小運按公曆年份計虛歲；抬頭的虛歲按農曆年。小運從時柱起，與大運同向。
- 司令：《淵海子平》人元司令分野，按出生所在節令、入節後天數分配（申月取己七、戊三、壬三、庚十七）。
- 暗合：子巳、子戌、丑寅、卯申、午亥。
- 刑：由三合局對三會方推出（子卯互刑、寅巳申、丑戌未、辰午酉亥自刑）；破：陽支加九、陰支加三。
- 神煞：見上方「神煞」一節。
- 命宮、身宮：以節令月與時支（寅=1 編號）算，命宮＝26−(月+時)，身宮＝2+(月+時)，天干用五虎遁；胎元＝月干進一、月支進三。

## 開發

原始碼在 `src/`，`node build.js` 組成 `dist/bazi.html`（獨立檔）與 `dist/artifact.html`（給 Artifact 發布）；資料夾裡的 `bazi.html` 就是最新一次組好的獨立檔。`node tests/acceptance.js bazi.html` 跑計算驗收（不帶參數則測 `src/engine.js`）；`node tests/ui.js` 用 Playwright 在桌面 1366 與手機 390 寬度走一遍介面（含主題切換、合盤對照對方、模擬帳戶同步）；`node tests/perf.js` 量開頁與切頁時間。
