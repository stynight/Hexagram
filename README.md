# Hexagram

## 八字排盤合盤

單一 HTML 的八字排盤與合盤工具：[`bazi-paipan/bazi.html`](bazi-paipan/bazi.html)，下載後用瀏覽器打開即可使用。

公曆、農曆、四柱三種輸入；基本排盤、專業細盤（大運、流年、流月、流日、流時五條可橫滑的干支條）、兩人合盤（可讓流年對照對方原局）與可調權重的關係清單；近四十種神煞，流派有分歧處可切換；四柱可一鍵複製，在命盤表裡拖選也按柱複製；案例可存檔、改名、刪除；主題可從十二種配色挑選或自訂。算法說明與驗收結果見 [`bazi-paipan/README.md`](bazi-paipan/README.md)。

## 六爻納甲排盤

單一 HTML 的六爻排盤工具：[`liuyao-paipan/liuyao.html`](liuyao-paipan/liuyao.html)，下載後用瀏覽器打開即可使用。

數字、手動六爻、時間（梅花易數）三種起卦；排出本卦變卦、卦宮世應、納甲、六親、六神、伏神與旬空，標出月破、日沖、暗動、臨月建、臨日與動爻的回頭生剋、化進化退、化空化破；關係清單先論合沖、再論生剋，依力量排序；附卦辭、爻辭、大小象原文；卦例可存檔、改名、刪除、匯出匯入。規則出處、驗收用例與曆算互核結果見 [`liuyao-paipan/README.md`](liuyao-paipan/README.md)。
