# 加刑以後的偏枯（v4）

`model.js` 的 v3 沒有算刑。這裡另開 `model-xing.js`，把 v3 的步驟抄過去，在合之後、沖之前加上刑，叫 v4。`model.js`、`README.md` 和原有的 `data/` 都沒有改動。

```
node run-xing.js
```

約 25 秒跑完 1804–2043 四輪甲子，寫出：

- `data/xing.json`：每個年柱 240 年平均的 v3、v4 極端盤比例，和 v4 的四輪各自的比例。
- `data/xing-months.json`：1984–2043 這一輪，每個年柱十二個月柱的 v3、v4 極端盤比例。

## 規則

刑只加力、不扣力，每支加兩成：把該支力量的兩成，全部加給一行。

- 自刑（辰辰、午午、酉酉、亥亥）、寅巳、巳申：要有月支參與，加給出生那天月令司令的藏干（`buildChart` 的 `siling`）；沒有月支就不加。自刑相鄰全額、隔一柱三成；寅巳、巳申只認相鄰。
- 丑戌未：只加本氣土，藏干不動；相鄰全額、隔一柱三成，不看月支。
- 子卯不加。

沒有算的：蓋頭（例如丁亥、己亥自合化木）、日主、寅亥巳申的排列順序。這些要看情況，留給看盤的人。

## 結論

- 60 個年柱裡 57 個變得更容易偏，丁卯不變，只有壬子（22.9% → 22.7%）、乙卯（20.3% → 20.0%）微跌：別的行被刑加力，水、木相對變少。
- 漲最多的是丑戌未：己未 +3.82、己丑 +3.74、戊戌 +3.70、庚戌 +2.04 個百分點。按年支平均：戌 +1.94、未 +1.80、丑 +1.77、酉 +1.32、午 +0.87、辰 +0.75、亥 +0.64、寅 +0.48、申 +0.45、巳 +0.38、子 +0.37、卯 +0.12。
- 前六名從辛酉、戊辰、壬子、癸亥、戊戌、戊申，變成辛酉 25.6%、戊辰 24.9%、戊戌 24.9%、壬子 22.7%、己未 22.3%、己丑 22.0%。辛酉四輪還是每輪第一。
- 按年干平均：甲 9.7 → 10.2、乙 11.4 → 12.0、丙 8.6 → 9.4、丁 13.0 → 13.6、戊 20.1 → 21.7、己 14.1 → 16.1、庚 11.1 → 11.8、辛 11.3 → 12.2、壬 14.7 → 15.2、癸 16.8 → 17.7。己漲最多，戊己年更偏了。
- 各月變化最大的是土月碰上土年：己丑年甲戌月 27.4% → 50.0%、庚戌年己丑月 21.5% → 43.2%、己未年甲戌月 26.0% → 46.8%。自刑裡最大的是癸酉年辛酉月 74.5% → 89.7%、辛酉年丁酉月 68.5% → 84.2%。
- 先試過一個粗算版本：自刑把整個地支平均放大兩成，不分司令，也不算丑戌未。那個版本前六名一個都不變；照上面的規則細算，前六名換了兩個。刑會不會改變結論，主要取決於丑戌未怎麼算。
